# 图论与魔方

一个**单文件**交互式网页：把 3×3 魔方的 54 张贴纸，映射成一张「三族同心圆的交点图」——魔方的每一个状态，都对应圆环上 54 个彩色点的一种排布。

## 在线玩

👉 **https://meishenmolan.github.io/graphcube/**

（也可以下载 `index.html` 双击打开——单文件、零依赖、离线可用）

## 玩法

**魔方（下半部分）**
- **按住贴纸滑动** → 转动该层（松手前会先高亮"将要转的整层"，转哪层、往哪转一目了然）
- **拖动空白处 / 两根手指拖** → 旋转视角（连续球面旋转，可以滚过顶点、转满 360°）
- 底部按钮：**打乱 / 撤销 / 复位**
- 移动端做了优化：手指点偏一点也能抓住贴纸、斜着拖也不会转错方向

**圆环（上半部分）= 魔方状态的映射**
- 54 个点 ↔ 魔方 54 张贴纸，**颜色一一对应**
- 转动时，对应圆环上的点会**流动**到新位置（12 个点沿环滑动、8 个点原地自转）
- 正在转动的圆环以**橙色高亮**
- **按住魔方上任意贴纸** → 圆环上联动点亮它对应的点；再打开"圈出相邻贴纸"还能看到它的 4 个邻居

**设置（右下角 ⚙）**
- 只显示魔方（隐藏圆环）、轴标注 x/y/z、圈出相邻贴纸、拖动灵敏度
- 视角：左右/上下反向开关、旋转速度、视角复位

## 这个映射是什么（简版）

- 三个圆心构成等边三角形，分别对应魔方的**三条坐标轴**；每个圆心带三个**同心圆**，对应这条轴上的**三层**
- 每张贴纸的位置 = 两族圆的**交点**（由它面内的两个坐标各决定一个环）
- 54 张贴纸恰好对应 **54 个交点**，两两不同 → **魔方状态 ⟷ 圆环上的配色**
- 一次转动 ⟷ 点沿圆环的一次置换

> 小提示：这是一张固定的「切片图」（每个圆 = 魔方的一层），不是魔方表面的照片，所以**跨棱相邻的两格在图上可能离得较远**——这是这种画法本身的性质（三个圆心 + 四组点的几何所决定）。

## 技术

- 纯 HTML + CSS + JavaScript，**单文件、零依赖、离线可用**
- 魔方：整数旋转矩阵引擎（26 个小方块），自校验动画
- 圆环：解析几何求圆族交点，54 点与贴纸一一绑定
- 交互：pointer 事件 + 拖动轴锁定 + 实时预览
